# MANNA — Forty Years in the Wilderness

An Exodus-inspired wilderness survival and colony-sim game.

## Versions

- `v1/` — the original Three.js game: Moses, the Pillar of Cloud/Fire, manna, water, stations, camp, market and survival systems.
- `v2/` — the current isometric edition, built as a self-contained 2D canvas game with a parchment HUD, twelve tribe population/livestock stats, a colony-sim slice, building and night raids.

## Run

```bash
npm install
npm run dev
```

Or run a version directly:

```bash
cd v2
npm run dev
```

## Verification

```bash
cd v2
npm test
npm run build
```
